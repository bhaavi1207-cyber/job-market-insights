# Job Market Insights Dashboard

A full data-to-UI portfolio project: a Python analysis pipeline turns raw
job-posting data into structured insights, and a React dashboard visualizes
them (role demand, salaries, skills, locations, trends).

## Why this project

Recruiters for frontend and junior software roles look for two things:
comfort with data, and the ability to ship a clean UI. This project shows
both in one repo:

- **Data analysis** (`analysis/`): parses a CSV of 600 job postings,
  aggregates role counts, average salaries, top skills, location mix, job
  types, and monthly posting trends, then exports them as JSON.
- **Frontend** (`frontend/`): a React + Vite dashboard (Recharts) that loads
  the generated JSON and renders stat cards, bar/pie/line charts, and a
  frontend-role skills deep-dive.

## Project structure

```
analysis/
  generate_data.py      # creates the sample dataset (synthetic, offline-friendly)
  analyze.py            # standard-library analysis -> output/insights.json
  data/job_postings.csv # 600-row sample dataset
  output/insights.json  # generated insights consumed by the frontend
frontend/
  src/App.jsx           # dashboard UI
  src/main.jsx, src/styles.css
  public/data/insights.json
```

## Run it

Analysis (Python 3.9+, no third-party packages needed):

```bash
cd analysis
python3 generate_data.py   # optional: regenerate the sample data
python3 analyze.py         # writes output/insights.json
cp output/insights.json ../frontend/public/data/insights.json
```

Dashboard (Node 18+):

```bash
cd frontend
npm install
npm run dev        # local dev server
npm run build      # production build in dist/
```

## What the analysis answers

- Which roles have the most postings, and what share does each hold?
- Average salary (LPA) by role.
- The most requested skills overall, and for Frontend Developer roles
  specifically.
- Location distribution, including the remote share.
- Posting volume month over month.
- Full-time vs internship vs contract split.

## Notes

- The dataset is **synthetic sample data** generated by
  `analysis/generate_data.py`, so the project runs offline with no API keys.
  Swap in a real postings export (e.g. scraped or Kaggle data with the same
  columns) and rerun `analyze.py` - the dashboard picks it up unchanged.
- Built with React 18, Vite 5, Recharts 2, and the Python standard library.
